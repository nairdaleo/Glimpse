Glimpse is a menu-bar utility with no Dock icon. After launch, click the small row of meters in the menu bar to open the detailed panel; the gear button opens Settings.

All features are free. The three consumable in-app purchases (com.tastyjam.glimpse.tip.small/.medium/.large) are optional tips in Settings › About › Support; they unlock nothing.

Glimpse reads local system counters only (CPU, memory, network interface counters, battery, disk capacity, thermal state). It makes no network requests, has no account and collects no data. It is sandboxed and needs no special permissions.

VPN: Glimpse has no VPN functionality. It does not provide, configure or route VPN connections and does not use the Network Extension framework. Network meters only read byte counters of existing network interfaces; these may include VPN tunnels created by other apps, which is why an earlier description mentioned VPNs; that wording has been removed.
- What user information is collected using VPN? None.
- For what purposes? Not applicable; no data is collected. Counters are shown on screen and kept only in memory and local preferences on the Mac.
- Is data shared with third parties? No. Glimpse makes no network requests and nothing leaves the Mac.
